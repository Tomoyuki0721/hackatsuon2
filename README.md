# 気仙沼市 政策・予算ダッシュボード 🐟

気仙沼市の**予算書・決算書・主要な施策の成果に関する説明書**を、
PDFごとではなく **事業単位** で結び付け、年度をまたいで「政策がどう変わってきたか」を
見るためのWebアプリです。

公開URL: https://tomoyuki0721.github.io/hackatsuon2/

## このサイトの考え方

「予算書・決算書を閲覧するサイト」ではなく、
**「一つの事業を、4つの視点に切り替えて見るサイト」** です。

| モード | 問い |
|---|---|
| 💰 予算モード | これからの予算は妥当か? |
| 📊 決算モード | 使ったお金で、どんな成果が出たか? |
| 🗣️ 一般質問モード | この政策はどこへ向かっているのか? |
| 🏠 市民モード | このお金は、私たちの暮らしにどう役立っている? |

各モードには［通常表示］と［詳細モード］があり、同じ事業ページ内で切り替わります。

政策のサイクル(予算 → 実施 → 決算 → 成果 → 課題 → 翌年度予算)を1本の線として
追えるようにすることが目的です。

## 数字の扱いについて(このプロジェクトの最重要ルール)

**このサイトに表示される数値・成果・課題は、すべて市の公開資料が出典です。**

- すべての値は出典(資料名・ページ・原文)を持ち、数字の横の「i」アイコンから確認できます
- 原典に無いものは推測で埋めず、**「資料記載なし」「未確認」「算出不可」** と明示します
- 本システムが計算した値(執行率・単価・増減率など)は、その旨を注記しています
- 特に 成果・KPI・課題・事業の統合について、AIによる創作は行っていません

信頼度が「中」「低」のデータには「要確認」「AI抽出・未確認」バッジが付きます。

## 技術構成

- **Next.js 14**(App Router)/ TypeScript / Tailwind CSS / Recharts
- `output: "export"` による**静的書き出し**(サーバー不要)
- **GitHub Actions** で自動ビルドし、**GitHub Pages** へ公開
  (Settings → Pages の Source は「GitHub Actions」)
- データベースは使わず、事業データは `data/projects/*.json` に1事業1ファイルで保持
  (将来 PostgreSQL 等へ移行しやすいよう、読み込みは `src/lib/data.ts` に集約)

## 動かし方

### GitHub Codespaces(推奨)

1. リポジトリの **Code** → **Codespaces** → **Create codespace on main**
2. セットアップ(2〜3分)が終わるのを待つ。`npm install` まで自動で走ります
3. ターミナルで:

```bash
npm run dev
```

ポート3000が自動転送され、プレビューが開きます。

### 手元のPC

Node.js 20 以上が必要です。

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # out/ に静的書き出し
```

### 公開

`main` に push すると GitHub Actions が自動でビルドし、GitHub Pages に反映されます
(1〜2分)。手動の操作は不要です。

## 対象資料と年度

令和4・6・7・8年度の一般会計 決算書 / 予算書 / 予算説明資料 / 主要な施策の成果に関する説明書
(計11ファイル)を原典としています。

- **令和5年度は資料が存在しない**ため、グラフや表では欠落年度として扱い、補間しません
- 令和7年度は事業別の予算書が無いため、予算額は決算書の「予算現額」を使用しています

詳細は [docs/source-inventory.md](docs/source-inventory.md) を参照してください。

## 現在の実装状況

**できていること**

- 4モード × 通常/詳細表示
- 事業ページ(KPI・主な事業内容・新規事業・財源内訳・成果・課題・論点)
- 全数値の出典表示、欠損データの明示
- 年度切り替え、経年推移グラフ
- トップページの検索・絞り込み(事業名/キーワード/所管課/政策分野/款/年度)
- 横断分析による自動抽出(新規・拡充事業、予算の増減、執行率が低い事業、
  成果指標が悪化した事業、一般財源負担が増えた事業、課題が継続している事業)
- 事業データ **5件**: 移住・定住促進事業、結婚支援事業、地域おこし協力隊事業(企画調査費)、
  子ども医療費助成事業、デジタル水産業戦略拠点事業

**未実装**

- PDFからの抽出スクリプト(現状は手作業で抽出し、出典を確認して登録)
- 議会の一般質問・答弁データ(原典資料が未提供のため「未確認」と表示)
- テスト
