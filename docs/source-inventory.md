## 2. 資料種別ごとの構造

### 2.1 決算書(#1〜#3)
- 構成: 「款/項/目」の見出し→「本年度予算額(現額) / 支出済額(決算額) / 翌年度繰越額 / 不用額 / 執行率」の総括表
  → 節ごとの内訳表 → 「説明」欄に**事業名+金額**が列挙される節別明細(予算書と同一の書式思想)
- 実例(#1, R7決算, 総務費 企画調査費 節): `移住・定住促進事業` の行に決算額(円単位)が入る
- 決算書には**予算現額**も載っているため、詳細予算書が欠けている年度(R7)の予算額を代替取得できる
- 款コードは全14区分(議会費〜予備費)で予算書と共通

### 2.2 予算書(#4〜#5、詳細版)
- 構成: 「(款)◯◯費 (項)◯◯費」→「目」ごとの表(本年度予算額/前年度予算額/比較/特定財源内訳/一般財源)
  → 「節」の説明欄に**事業名+金額**(円単位)が列挙。R8年度分は本セッション内で全款・全事業を
  手作業抽出済み(`scratchpad/r8_budget_by_kan.md`、実装時に転記して使う)
- 事業名の粒度は「総合計画策定事業」「移住・定住促進事業」のような具体名から、「一般行政経費」
  「職員人件費」のような包括的経費まで混在する。前者のみが「主要な施策」報告書と対応する

### 2.3 予算説明資料(#6〜#8)
- 各事業が1〜2ページの定型シートで記述される:
  `所管課` / `予算書ページ` / `予算科目(款項目)` / `予算額` / `事業名等` / `総計基本施策分類`
  / `目的` / `内容(事業概要)` / (該当する場合)`債務負担行為(事項/期間/限度額)` / `財源内訳`
- **`総計基本施策分類`が総合計画の政策分野コードで、`policy_category`のソースになる**
- 全事業ではなく主要事業(R8で195件)のみ収録。債務負担行為が中心のため、単年度予算額欄が
  「－」になっている事業も多い(その場合は詳細予算書側の金額を使う)

### 2.4 成果報告書(#9〜#11)
- 地方自治法第233条第5項に基づく決算附属書類。目次に「款ごとの事業名一覧+ページ番号」があり、
  これが**主要事業マスターリストの最有力候補**(全事業ではなく「主要な施策」に絞られているため、
  ユーザー要件「継続事業で予算・決算・成果の3資料に存在する事業」の母集団として最適)
- 各事業シートの構造: `所管課` / `予算科目(款項目)` / `総計基本施策分類` / `事業名` /
  `決算書ページ`(→決算書#1〜#3への相互参照キー) / `【目的】` / `【事業内容】`(サブ事業の内訳と
  数値実績が混在して書かれる、例:「空き家改修支援事業補助金 10,029千円」) / `【実施状況】`
  (定量実績、例:「相談件数347件」「移住者数35人」) / `【成果】`(定性・定量の総括) / `【課題】`
- 同一事業が複数年度の報告書に載っている場合、`事業名`は表記ゆれがほぼ無い(法定書類のため様式が
  安定している)ことを確認済み。款/項/目コードも年度を跨いで安定している

## 3. 事業を年度間で紐付けられるキー

優先度の高い順:

1. **`予算科目`(款/項/目コード)** — 4資料すべてに共通して現れる最も安定したキー。ただし「目」の
   統廃合が年度によって起きる可能性があるため単独では不十分
2. **事業名の完全一致** — 成果報告書・予算説明資料では表記が安定。予算書(節の説明欄)では
   「一般行政経費」等の包括名との混在に注意
3. **決算書ページ番号(成果報告書内の`決算書ページ`欄)** — 成果報告書→決算書への直接参照。
   ただし決算書側は年度ごとにページ割りが変わるため、あくまで「その年度の決算書」内でのみ有効
4. **所管課** — 補助的な突合根拠(同一事業なら通常変わらない)
5. **事業名のfuzzy一致/alias** — 「移住・定住促進事業」⇔「移住定住促進事業」等の表記ゆれ対策。
   今回確認した範囲(移住・定住促進事業/結婚支援事業/地域おこし協力隊事業/子ども医療費助成事業/
   デジタル水産業戦略拠点事業/まちづくり応援寄附金推進事業)では**表記ゆれは確認されなかった**
   (法定書類のため用語が統一されている)。ただし全事業を突合する際は候補として残す

## 4. 予算資料と決算・成果資料の対応関係

```
R4: [07一般会計決算書.pdf(決算)] ←→ [17主要な施策の成果説明書.pdf(成果・課題)]
     ※R4の詳細予算書は本リポジトリに無し

R6: [11令和6年度一般会計予算説明書.pdf(予算)]
    [12令和6年度一般会計予算説明資料.pdf(主要事業ナラティブ)]
      ↓
    [07 令和6年度一般会計決算書.pdf(決算)] ←→ [17 令和6年度主要な施策の成果に関する説明書.pdf(成果・課題)]

R7: [11 令和7年度一般会計予算説明資料.pdf(主要事業ナラティブのみ、詳細予算書なし)]
      ↓
    [05 令和7年度気仙沼市一般会計決算書.pdf(決算・予算現額)] ←→ [16 令和7年度主要な施策の成果に関する説明書.pdf(成果・課題)]

R8: [11 令和8年度一般会計予算説明書.pdf(予算・全款抽出済み)]
    [12 令和8年度一般会計予算説明資料.pdf(主要事業ナラティブ)]
      ↓
    決算・成果報告書は未公表(次年度)
```

政策サイクル(予算→実施→決算→成果→課題→翌年度予算)を実際にたどれるのは
**R6→R7の1サイクル分**(R6予算・決算・成果 → R7予算・決算・成果)が最も資料が揃っている。
R4は成果・決算のみ、R8は予算のみで、両端の参考値として使う。

## 5. パイロット候補事業(3〜5件)

いずれも款/項/目コード `2款1項7目`(企画調査費)等で款を跨がず、R4/R6/R7の成果報告書すべてに
事業名が確認できた(§3の突合キーで検証済み)。

| 事業名 | 款 | 選定理由 |
|---|---|---|
| **移住・定住促進事業**(フラッグシップ候補) | 2款(総務費) | サブ事業4本(移住・定住支援センター/ふるさとワーキングホリデー/空き家改修支援補助金/空き家取得補助金)、定量実績(相談件数・移住者数・空き家成約件数等)、成果・課題が最も豊富。R6/R8予算・R7決算・R4/R6/R7成果すべてで確認済み |
| 結婚支援事業 | 2款(総務費) | 予算・成果ともに全年度で確認済み。単一事業でシンプルな比較例に向く |

## 7. アーキテクチャ上の要確認事項(実装着手前に確認したいこと)

本リポジトリの `CLAUDE.md`(プロジェクト規約)は「ビルドツール禁止・素のHTML/CSS/JS・index.html直下・
GitHub Pagesでの静的公開」を前提としたハッカソン初心者向けスターターとして書かれている
(`README.md`もGitHub Pagesへの静的公開手順のみを解説)。

一方、今回の指示は Next.js + TypeScript + Tailwind による本格的なフルスタックアプリを想定しており、
これは以下の点でCLAUDE.md/README.mdの前提と衝突する:

- GitHub Pagesは静的ファイルのみのホスティングのため、Next.jsのAPI Routes/SSRはそのままでは動かない
  (`next export`による静的書き出しに限定するか、Vercel等の別ホスティングに切り替える必要がある)
- devcontainerは `http-server -p 8080` での静的プレビュー用に設定されており、`next dev`前提のポート
  設定(3000番)やNode依存関係のインストール手順が整っていない

→ 実装(Phase 3以降)に進む前に、**ホスティング方針(GitHub Pages継続 or 別サービスへ移行)**を
確認したい。今回はご指示通りNext.js/TypeScript/Tailwindを前提に進めるが、上記の対応方針だけ
判断をお願いしたい。
